# Vault rules

This vault is Claude's long-term memory and thinking space for CTF work.
Notes may be written in Arabic or English.

## Use
- At the start of a session, read `Home.md`, then the technique and lesson notes that match
  the category you are about to work on.
- Think in `Thoughts/`. Free-form notes are fine there.
- After a challenge, solved or not, create `Challenges/<event>-<name>.md` from
  `Templates/Challenge.md`. Move anything reusable into `Techniques/` or `Lessons/`.
- Link related notes with `[[wikilinks]]`. One idea per note; update instead of duplicating.
- Keep `Home.md` current when adding important notes.
- Do not store live credentials or secrets. Flags from finished CTFs are fine.

## Folders
| Folder | Purpose |
|---|---|
| `Inbox/` | quick captures to sort later |
| `Challenges/` | one note per challenge |
| `Techniques/` | reusable how-tos by category |
| `Lessons/` | mistakes, dead ends, rules of thumb |
| `Tools/` | per-tool cheat sheets and quirks |
| `Thoughts/` | free reasoning and hypotheses |
| `Journal/` | dated session logs |
| `Templates/` | note templates |
